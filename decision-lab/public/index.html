Model interfaces & backend availability +

The model menu reflects this server’s configured backends and image support. Disabled models show why they are unavailable. Clef Flash and Jev use typed choices; GPT-6 Luna uses a structured JSON chat completion without choice probabilities. OpenRouter Clef is pinned to Cloudflare without fallback routing; Luna chat uses reasoning effort none.

The self-hosted GPU is selected by default when configured. Additional hosted models remain selectable when OpenRouter credentials are available. Each lane identifies its selected model; failures are reported without switching models. Provider round-trip time and any server-reported inference time are shown separately.

Form values come from the displayed source record. The model chooses bounded categories and candidates; the browser applies those choices. No email, ticket, purchase, or external website is modified.
